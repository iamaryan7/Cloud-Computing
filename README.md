# ☁️ What is Cloud Computing?

Cloud Computing is the delivery of computing services such as:

* Servers
* Storage
* Databases
* Networking
* Analytics
* Artificial Intelligence
* Software

over the Internet ("The Cloud") on a pay-as-you-go basis.

### Simple Definition

> Cloud Computing means using computing resources through the Internet instead of owning and managing physical hardware.

✅ Business Continuity

# ⭐ Characteristics of Cloud Computing

## 1. On-Demand Self-Service

Users can provision resources without human interaction.

## 2. Broad Network Access

Access through mobile phones, tablets, laptops, and desktops.

## 3. Resource Pooling

Multiple customers share the same infrastructure.

## 4. Rapid Elasticity

Resources scale up or down automatically.

## 5. Measured Service

Pay only for what you use.

# 🏗 Service Models

## IaaS (Infrastructure as a Service)

Provides:

* Virtual Machines
* Storage
* Networking
* Servers

### Examples

* AWS EC2
* Azure Virtual Machines
* Google Compute Engine

---

## PaaS (Platform as a Service)

Provides:

* Runtime Environment
* Development Tools
* Databases
* Middleware

### Examples

* Google App Engine
* Heroku
* Azure App Service

---

## SaaS (Software as a Service)

Ready-to-use software delivered through the Internet.

### Examples

* Gmail
* Microsoft 365
* Zoom
* Google Docs

---

# 🌐 Deployment Models

## Public Cloud

Shared infrastructure available to everyone.

### Examples

* AWS
* Azure
* GCP

## Private Cloud

Used by a single organization.

## Community Cloud

Shared by organizations with common goals.

## Hybrid Cloud

Combination of Public + Private Cloud.
